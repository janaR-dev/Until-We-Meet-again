# ITF J200 Maadi — Farewell & Appreciation Page

A standalone, responsive HTML/CSS/JavaScript tribute page for the ITF J200 tournament at Maadi Club, Egypt.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Add your real photos to `assets/photos/` using the filenames below.

## Add your tournament photos
The page automatically looks for the first available format in this order: `.jpg`, `.jpeg`, `.png`, `.webp`.

| Filename | Suggested photo |
|---|---|
| `hero.jpg` | Best wide photo of Maadi courts / tournament atmosphere |
| `team.jpg` | Group photo, team, or tournament gathering |
| `players.jpg` | Players on court or a candid player moment |
| `match.jpg` | Action shot from a match |
| `friends.jpg` | Players together off court / shared moment |
| `sunset.jpg` | Courts at golden hour, or a quiet detail |
| `j300.jpg` | Wide court photo for the closing J300 message |

Keep the filenames exactly as shown. If a photo is missing, a designed placeholder will appear. Recommended: landscape photos at least 1600px wide for `hero`, `team`, `players`, and `j300`; 1000px wide is sufficient for the smaller gallery images.

## Customize the page
- Edit all copy and section headings in `index.html`.
- Adjust colors, type, spacing, and responsive layouts in `styles.css`.
- Navigation, scroll progress, reveal animations, and photo loading are in `script.js`.
- Change “2026” in the hero eyebrow if needed.
- The page uses Google Fonts when online and falls back to system fonts if offline.

## Before publishing
- Confirm the tournament year and official event wording.
- Ensure you have permission to publish player photos, especially images of juniors.
- Use the official ITF / Maadi Club logos only if authorized; the current “M” mark is a simple text treatment, not an official logo.
- Verify that descriptions of the web app and services accurately reflect what was provided.
